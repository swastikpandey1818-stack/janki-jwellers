# Shree Janki Jewellers - billing app (v1.7.0)

Features: invoices (gold / silver / others, making, GST, UPI QR PDF), part payment & dues, Day Book,
**new in 1.7:** dashboard gold/silver rate (set yourself or fetch online), customer list (birthday / anniversary),
advance & booking (rate lock, deliver into a bill), WhatsApp reminders (dues, deliveries, wishes),
backup reminder, full backup/restore of everything (older 1.x backups still restore).

Build the APK: push to GitHub, run the "Build Android APK" workflow.
